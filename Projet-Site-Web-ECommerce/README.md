## 📌 Présentation du Projet

Projet de première année (BUT R&T) portant sur la création complète d'un site web marchand dynamique sans framework, dédié à la vente de mangas en ligne.

---

## 🎯 Fonctionnalités Développées

* 🛍️ **Catalogue Produit :** Affichage dynamique des articles depuis la base de données MySQL.
* 👤 **Gestion Utilisateur :** Inscription, connexion et gestion de sessions en PHP.
* 🎨 **Interface Graphique :** Intégration sur-mesure en HTML5 et feuilles de style CSS3.

---

## 🛠️ Stack Technique

* **Backend :** PHP
* **Frontend :** HTML5, CSS3
* **Base de données :** MySQL
