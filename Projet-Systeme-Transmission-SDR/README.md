## 📌 Présentation du Projet

Étude et mise en œuvre d'un système de transmission sans-fil basé sur la technologie **SDR** (*Software Defined Radio*). L'objectif était de comprendre le passage des traitements matériels traditionnels (filtres, modulateurs) vers le traitement logiciel de signaux analogiques et numériques.

---

## 🎯 Objectifs Techniques

* 📻 **Traitement du Signal :** Réception et démodulation de signaux radiofréquences via un boîtier SDR.
* 💻 **Développement Logiciel :** Création de chaînes de traitement sous environnement GNU/Linux.
* ✈️ **Cas d'usage :** Capture et décodage de trames radio (ex: signaux ADS-B pour le suivi d'avions) à l'aide de scripts Python.

---

## 🛠️ Stack Technique

* **Matériel :** Clés / Boîtiers SDR
* **Logiciels :** GNU Radio, Python, Linux
